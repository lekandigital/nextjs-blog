# Next.js Blog Template

A clean, minimalist, and feature-rich blog template built with Next.js, Tailwind CSS, and MDX.

## Features

- **MDX Support**: Write your posts in Markdown with React components.
- **Custom Audio Player**: Built-in audio player for narrated posts or podcasts.
- **Clean Design**: Minimalist aesthetic focused on readability.
- **Responsive**: Fully responsive design for all devices.
- **SEO Optimized**: Built-in SEO best practices.
- **Dark Mode**: Support for light and dark themes.

## Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/your-blog-repo.git
    cd your-blog-repo
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```

    Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
